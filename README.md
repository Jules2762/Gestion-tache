# Task Manager CLI

Application de gestion de tâches développée en Dart.

## Fonctionnalités

- Ajouter une tâche
- Lister les tâches
- Trier par priorité
- Trier par date
- Marquer une tâche comme terminée
- Supprimer une tâche
- Sauvegarde des données au format JSON
- Tests unitaires

## Installation

```bash
dart pub get
```

## Lancer l'application

```bash
dart run
```

## Lancer les tests

```bash
dart test
```
